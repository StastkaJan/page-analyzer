# PA-024: Verify the release candidate against all first-version criteria

Stage: [S8 - Deployment integration and release verification](../roadmap.md#s8-deployment-integration-and-release-verification)
Status: Not started
Depends on: [PA-022](PA-022.md), [PA-023](PA-023.md)

## Expected result

Produce the final evidence that the intended deployment supports the complete first-version journey.

## Scope

- Run submission/report/rescan/comparison for both profiles, including partial/failed scans and keyboard operation.
- Verify deployment-sensitive egress, isolation, authentication, quotas, retention/deletion, and recovery.
- Map product acceptance criteria and implementation verification requirements to actual results, sample reports, and known limitations.

## Acceptance criteria

- [ ] Every required criterion has recorded evidence from the intended deployment or an explicit unresolved blocker.
- [ ] No production-user flow exposes fixtures; reports record actual engine versions/conditions and remain private.
- [ ] S8 is marked done only after required checks pass; release readiness itself does not publish the service.

## Verification

- Execute the full acceptance matrix and record commands, environment/version/configuration identifiers, and results.
- Review the release record for missing evidence and unresolved blockers; retain real report/comparison examples without sensitive content.

## Out of scope

Publishing the release, post-MVP features, and accepting planned checks as completed evidence.

Not implemented. When completing this ticket, record changed files/PR, exact checks and outcomes, demonstration evidence, and remaining limitations here.
