# PA-012: Enable the real submission-to-report journey

Stage: [S4 - Real isolated browser scans](../roadmap.md#s4-real-isolated-browser-scans)
Status: Not started
Depends on: [PA-010](PA-010.md), [PA-011](PA-011.md)

## Expected result

Let a user submit a permitted page and reopen a basic real report without operator tools.

## Scope

- Connect public URL/profile submission to the background runner and existing progress/report views.
- Display requested/final URLs, category results, evidence, versions, conditions, partial coverage, and lab measurement labels.
- Keep fixture mode separate and disabled for production users with no automatic sample fallback.

## Acceptance criteria

- [ ] Both profiles complete submission, progress, report delivery, and later retrieval through the interface.
- [ ] Blocked targets and failed/partial scans have honest, safe explanations; refreshing does not resubmit.
- [ ] Real reports contain real scan evidence and stay private; production users cannot obtain simulated results as scans.

## Verification

- Demonstrate the complete path on controlled public targets for both profiles and failure/partial outcomes.
- Verify the fixture guard, keyboard path, sensitive-data handling, and record the S4 stage evidence.

## Out of scope

Full curated guidance, rescan comparison, and public deployment.
