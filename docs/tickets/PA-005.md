# PA-005: Store artifacts privately and authorize retrieval

Stage: [S2 - Private persisted scans](../roadmap.md#s2-private-persisted-scans)
Status: Not started
Depends on: [PA-004](PA-004.md)

## Expected result

Attach permitted evidence to a saved report without exposing storage internals.

## Scope

- Choose artifact storage and define capture policy, content types, size limits, and opaque references.
- Save sample artifacts with owning scan/attempt metadata and validate references at application boundaries.
- Authorize downloads and prevent target HTML or untrusted content from executing as application content.

## Acceptance criteria

- [ ] Owners can retrieve permitted evidence; unauthenticated and unrelated users cannot.
- [ ] Arbitrary paths, mismatched ownership, disallowed types, and oversized artifacts are rejected.
- [ ] Storage is private and reports do not expose public bucket URLs or trusted executable captured HTML.

## Verification

- Exercise allowed downloads and cross-owner/path/reference manipulation cases.
- Check type/size limits and captured-content handling; record storage and capture decisions.

## Out of scope

Automated expiration/deletion, public sharing, and unrestricted page capture.
