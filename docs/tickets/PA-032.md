# PA-032: Establish application database schema and setup

Stage: [S2 - Private persisted scans](../roadmap.md#s2-private-persisted-scans)
Status: Not started
Depends on: [PA-030](PA-030.md)

## Expected result

Create a reproducible application-owned schema ready for private scan persistence.

## Scope

- Choose the database and define schemas for owner references, scans, attempts, accepted results, and lifecycle metadata using existing contracts.
- Add versioned schema setup/migration commands, appropriate relationships/uniqueness constraints, and fixtures for the persistence layer.
- Document database credentials/ownership, initial schema compatibility, and non-destructive setup behavior; the scanner receives no application database credentials.

## Acceptance criteria

- [ ] An empty database can be initialized reproducibly and rerunning supported setup does not erase existing data.
- [ ] Owner/scan/attempt/result relationships prevent invalid references and duplicate accepted-result records at the responsible storage layer.
- [ ] The application alone owns database writes; chosen constraints and migration assumptions are documented and tested.

## Verification

- Run setup on an empty database and the supported rerun/upgrade path with retained sample records.
- Exercise relationship/uniqueness constraints and inspect credential separation.

## Out of scope

Application report endpoints, choosing user identity again, queue infrastructure, and destructive schema reset as a normal startup path.
