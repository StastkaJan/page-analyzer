# PA-009: Bound retries and recover abandoned scans

Stage: [S3 - Background execution and recovery](../roadmap.md#s3-background-execution-and-recovery)
Status: Not started
Depends on: [PA-007](PA-007.md), [PA-008](PA-008.md), [PA-033](PA-033.md)

## Expected result

Make worker and delivery failure terminate predictably while preserving useful output.

## Scope

- Enforce PA-033's recorded numeric queue/execution/delivery deadlines, lease renewal, maximum attempts, and retry/backoff policy; do not introduce a second set of defaults.
- Recover worker loss, fence expired attempts, and avoid retries for deterministic rejection.
- Preserve partial output, show safe failures, and document attempt ownership and recovery settings.

## Acceptance criteria

- [ ] Worker loss and exhausted retries resolve into a valid terminal state within policy.
- [ ] An old attempt finishing after recovery cannot replace the new attempt's result.
- [ ] Useful partial analysis is retained and labeled; no usable analysis produces failed status.

## Verification

- Interrupt workers/delivery, exhaust retries, and deliver late results.
- Demonstrate all persisted lifecycle outcomes and record S3 recovery evidence with configured deadlines.

## Out of scope

Public operation quotas and real-engine recovery details that require the browser adapter.
