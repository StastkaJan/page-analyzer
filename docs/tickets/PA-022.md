# PA-022: Prepare the reproducible deployment configuration

Stage: [S8 - Deployment integration and release verification](../roadmap.md#s8-deployment-integration-and-release-verification)
Status: Not started
Depends on: [PA-021](PA-021.md)

## Expected result

Assemble the actual services and backing stores for the selected deployment environment.

## Scope

- Select the concrete hosting configuration within PA-025/PA-026's proven constraints and document dependencies, service identities, secret provisioning, network policies, and private storage. If constraints change, re-prove affected feasibility checks.
- Provide reproducible install/schema/start/deploy commands and health/readiness checks for actual dependencies.
- Disable fixture mode for production users and preserve independent service deployment.

## Acceptance criteria

- [ ] Configuration includes both services, interface, queue, database, and private artifact storage with no embedded secrets.
- [ ] Missing required dependencies/configuration produce meaningful readiness failures.
- [ ] Deployment instructions identify required authorized external provisioning and do not claim an unavailable environment is running.

## Verification

- Validate configuration and startup/readiness behavior in an available suitable environment.
- Verify production fixture guards and secret handling; record external prerequisites that remain unfulfilled.

## Out of scope

Purchasing/provisioning external resources or publishing the service without an authorized task.
