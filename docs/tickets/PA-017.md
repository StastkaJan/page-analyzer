# PA-017: Compare findings using explicit coverage equivalence

Stage: [S6 - Rescan, history, and comparison](../roadmap.md#s6-rescan-history-and-comparison)
Status: Not started
Depends on: [PA-013](PA-013.md), [PA-016](PA-016.md), [PA-035](PA-035.md)

## Expected result

Classify changes only when evidence supports the conclusion.

## Scope

- Implement PA-035's decision matrix using stable finding identities and PA-027's supported rule/target coverage; do not infer evidence the engine did not provide.
- Compute persistent, resolved, new, and unverified outcomes using the domain contract.
- Handle changed profiles/engines/conditions/destinations and removed or not-applicable targets explicitly; authorize both inputs.

## Acceptance criteria

- [ ] Absence alone never implies resolution or a new finding without successful comparable coverage.
- [ ] Failed/skipped/manual/missing coverage and incompatible identities yield unverified where equivalence is unavailable.
- [ ] Unauthorized or different-page inputs are rejected; score changes are observations rather than causation claims.

## Verification

- Run paired fixtures for all classifications, removed targets, changed conditions, and missing checks.
- Verify query-sensitive page identity, mismatched versions/profiles, and access to both input reports.

## Out of scope

Heuristic claims of improvement without evidence and mutation of source reports.
