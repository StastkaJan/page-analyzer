# PA-014: Add deterministic priorities and evidence-backed guidance

Stage: [S5 - Actionable reports and recommendations](../roadmap.md#s5-actionable-reports-and-recommendations)
Status: Not started
Depends on: [PA-013](PA-013.md)

## Expected result

Explain what to fix first and how to verify it using actual findings.

## Scope

- Define separate product priority and effort rules with rationale and unknown effort.
- Map supported findings to impact explanations, concrete fixes, trusted documentation, and verification steps.
- Retain engine severity/scores and keep unsupported advice explicitly unavailable rather than invented.

## Acceptance criteria

- [ ] Every recommendation traces to a rule and observed evidence or curated guidance tied to it.
- [ ] Identical input yields identical priorities; engine severity is unchanged and unknown effort stays unknown.
- [ ] Advice identifies affected targets where available and makes no unsupported quantitative improvement claims.

## Verification

- Exercise representative rule mappings, missing evidence, unknown effort, and unmapped findings.
- Review generated guidance against source evidence and record rule locations and priority decisions.

## Out of scope

LLM calls, invented measurements, and an unexplained combined score.
