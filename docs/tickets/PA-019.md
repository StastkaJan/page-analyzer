# PA-019: Enforce request quotas and bounded admission

Stage: [S7 - Operating limits, retention, and diagnostics](../roadmap.md#s7-operating-limits-retention-and-diagnostics)
Status: Not started
Depends on: [PA-036](PA-036.md)

## Expected result

Keep accepted scan work within documented capacity and operating budgets.

## Scope

- Enforce PA-036's numeric admission quotas/caps with PA-033 timing policy and PA-034 resource budgets; keep one authoritative setting for each limit.
- Enforce admission limits with actionable UI/API responses when capacity is unavailable.
- Preserve bounded recovery and isolation under concurrency; expose safe queue/outcome timing diagnostics.

## Acceptance criteria

- [ ] Excess requests do not create unbounded queued work or browser processes.
- [ ] Accepted scans finish or fail within configured policies, and admission errors explain the user action.
- [ ] Concurrent requests cannot bypass quotas or access another user's data.

## Verification

- Exercise concurrent admission, backlog, execution limits, and retry exhaustion.
- Record tested limits, timing evidence, and safe user-facing capacity responses.

## Out of scope

Autoscaling platforms without demonstrated need and billing-based quotas.
