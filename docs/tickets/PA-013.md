# PA-013: Stabilize finding identities and consolidate demonstrated duplicates

Stage: [S5 - Actionable reports and recommendations](../roadmap.md#s5-actionable-reports-and-recommendations)
Status: Not started
Depends on: [PA-012](PA-012.md)

## Expected result

Normalize findings for trustworthy presentation and later comparison without losing evidence.

## Scope

- Version rule/target normalization using PA-027's evidence and limitations; keep original measurements and all source references.
- Group findings by category; merge only the same issue and compatible target.
- Retain passed, finding, not-applicable, manual-review, failed, and skipped coverage separately.

## Acceptance criteria

- [ ] Changing prose or measured numeric values does not change finding identity.
- [ ] Different issues on the same element remain distinct and consolidation retains every source.
- [ ] Coverage and category scores preserve original meanings and missing data stays unavailable.

## Verification

- Run representative normalization/consolidation fixtures including target and text variations.
- Verify stable identities, no evidence loss, and distinct incomplete/manual outcomes.

## Out of scope

Another engine solely to demonstrate deduplication, recommendation rules, and comparison classifications.
